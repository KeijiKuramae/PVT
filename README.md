# PVT-B

睡眠→翌日のうっかり型エラー予測の研究（卒業研究）で使う、自作の精神運動覚醒課題（Psychomotor Vigilance Task）。

3分版（PVT-B）を日課とし、機器間変換の較正のため週1回だけ10分版を併用する。

## 設計方針

**正確な絶対値を測ることではなく、同一個人の日々の変動を、後から定義を変えられる形で残すこと。**

ブラウザとタッチ入力の遅延により、反応時間の絶対値には端末固有の系統的な上乗せがある。文献値との直接比較はできない。ただし同一端末・同一個人で一貫していれば日々の変動には影響しないため、本用途では許容している。

- **試行レベルで保存する** — 試行番号・刺激間間隔・反応時間・フライングを1試行ずつ記録する。ラプス判定はアプリ側で行わない（閾値は解析時に可変）
- **時間計測は `performance.now()`** — `Date.now()` はシステム時計の補正で飛ぶ
- **刺激提示時刻は実描画フレームの時刻** — `requestAnimationFrame` のタイムスタンプを採る
- **完全にオフラインで動く** — データは端末内（IndexedDB）にのみ保存され、外部に送信しない

## 使い方

1. HTTPS で配信されたページを開き、**ホーム画面に追加**する
   （iOS Safari は7日間アクセスのないサイトの IndexedDB を自動削除する。PWA として追加していれば対象外）
2. 起床直後に「PVT を開始」。初回に起床時刻を打刻する
3. 終了後に `.ics` を書き出し、カレンダーに取り込む。その日の残りのセッションが開始時刻ちょうどに通知される
4. カフェイン・仮眠などは「イベント打刻」から記録する
5. **週に一度、JSON バックアップを書き出して PC に退避する**

## セッション

| ラベル | タイミング | 扱い |
|---|---|---|
| `wake+0` | 起床直後（±5分） | 必須。カフェイン・シャワー・強い光より前 |
| `wake+15` | 起床+15分 | 必須 |
| `wake+30` | 起床+30分 | 必須 |
| `noon` | 12:00固定・昼食の前 | 必須 |
| `wake+8h` | 起床+8時間 | 必須 |
| `wake+12h` | 起床+12時間 | 任意（起きていれば打つ） |
| `pvt10` | 週1回・`wake+8h` の枠 | 必須。10分版 |
| `off_schedule` | 上記のどの窓にも入らない | 記録は残す |

ラベルは集計の便宜であり、**解析の主変数は `tau_min`（起床打刻からの実経過分）**。セッションを飛ばしても、未実施の予定ラベルが繰り上がることはない。

## 運用上の注意

- **睡眠を整えない。** 起床時刻・睡眠時間の自然なばらつきが分析上の資産になる
- **カフェイン・仮眠を禁止しない。記録する。** ただし `wake+0` はカフェインより前に打つ
- 最初の10セッション程度は練習効果があるため、解析から除外する前提で日数を積む

## 出力

| ファイル | 内容 |
|---|---|
| `trials.csv` | `session_id, trial, isi_ms, isi_actual_ms, rt_ms, false_start, stim_ts, resp_ts` |
| `sessions.csv` | `session_id, started_at, label, tau_min, subjective_kss, wake_time_self_report, note` |
| `events.csv` | `event_ts, event_type, value` |

書き出しは毎回ではなく、押した時点の累積データが全部出る。
